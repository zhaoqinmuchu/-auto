## 一、结论先行（直接回答用户问题）

### 1.1 一句话结论

**原文从未规定「跳空/缺口本身构成线段划分的依据」。恰恰相反：跳空只被定性为「最低级别的走势成分」，它对笔和线段的划分不产生任何特殊规则——「跳空不改变任何事情，如果这缺口在线段里，还是线段；在笔里，还是笔」（第四册 ppt1667）。**

因此，大幅向上跳空后画不出下降线段，**在原文口径下是可能完全正确的**：跳空不自动结束上涨线段，下降线段要成立，必须走过第 67 课「第二种情况」的确认程序。

### 1.2 「有缺口时，反向线段如何确认」的原文档位（核心）

判据唯一落在 **第 67 课《线段的划分标准》**，并由 **第 77 课**给出一处关键简化、由 **第 78/79 课与三处答疑**补充操作细节：

| 层级 | 原文出处 | 规则 |
|---|---|---|
| 判据总纲 | 第 67 课，第四册 PDF PAGE 278-281，印刷页 pp1536-1539，txt L5395-5465 | 线段结束的两种**完全分类**，唯一判据是「特征序列的分型中，第一和第二元素间**是否存在特征序列的缺口**」 |
| 有缺口 → 第二种情况 | 同上 pp1538，L5433-5444 | 有缺口时，**必须**「从该分型最高点开始的向下一笔开始的序列的特征序列出现底分型」，线段才算结束 |
| 放松条件 | 同上 pp1538，L5448-5449 | 「在第二种情况下，后一特征序列**不一定封闭**前一特征序列相应的缺口，而且，第二个序列中的分型，**不分第一二种情况，只要有分型就可以**」 |
| 简化 | 第 77 课，第五册 PDF PAGE 18-19，pp1698-1699，L495-508 | 第二特征序列「**不再分第一、二种情况了**」，理由是一旦递归要求回补会推出「区间无限缩小成一个点」的悖论 |
| 落地算法 | 第 71 课，第四册 pp1607，L6894-6899 | 「假设某转折点是两线段的分界点，然后对此用线段划分的两种情况去考察是否满足」；第一元素＝转折点前线段最后一个特征元素，第二元素＝转折后第一笔 |
| 否定性结论 | 第 71 课附答疑 2007-08-21，pp1621，L7164-7172；第 76 课附答疑 2007-09-05，pp1689-1690 | 特征序列缺口被封闭 ≠ 线段被破坏；「这只是笔破坏，没有线段破坏」 |

**所以「有缺口时反向线段成立」的必要条件（原文口径）是：**

1. 以大幅跳空前的最高点（假设转折点）为界，取「转折点前线段最后一个特征元素」与「转折点后第一笔」比较区间，确认两者之间存在**特征序列缺口**（区间不重合）→ 判为第二种情况（第 67 课定义 + 第 71 课 L6897-6899）；
2. 反之，若无缺口，属第一种情况：只要形成特征序列分型，「任何三笔其实都构成对前面线段的破坏」（2007-08-16 16:54，第四册 pp1601，L6758-6762）；
3. 属于第二种情况时，**反向走势必须自己走出第二特征序列的分型**——对「向下线段」而言，就是从跳空高点开始的向下序列里，其**向上笔构成的特征序列出现底分型**；第 77 课明确这一步不再分第一/第二种情况，也**不要求回补**跳空缺口；
4. 若无第二特征序列分型，则「原来的下跌没结束」/「原来的线段没被破坏」（第 76 课附答疑 16:33，pp1689，L286-289；第 78 课 L677-679）；
5. 另需满足线段自身的成立条件：至少三笔、笔数为单数、**开始三笔必须有重合**（第 77 课 pp1698，L478-483）；第 79 课还强调，只有一笔时「必须再看两笔才知道是否满足……所以该图属于未完成的图」（pp1736-1737，L1163-1165）。

### 1.3 最容易搞错的一处：两个「缺口」不是同一个概念

这是判断程序行为是否正确的**首要排查点**：

- **价格跳空缺口**（第 77 课定义）：「何谓缺口，就是在该单位K线图上两相邻的K线间出现没有成交的区间」（第五册 pp1694，L399-400）。这是一个**成交区间**概念，描述行情。
- **特征序列的缺口**（第 67 课定义）：「特征序列两相邻元素间没有重合区间，称为该序列的一个缺口」（第四册 pp1536，L5404-5405）。这是一个**结构区间**概念，是线段划分的判据。

两者不等价：大幅向上跳空**可能**造成第 67 课意义上的特征序列缺口，但第 67 课的缺口只要求「两相邻特征元素区间不重合」，**并不要求中间存在无成交的价格区间**；反之，一个很小的盘中跳空也未必造成特征元素不重合。

> 程序做线段划分时，只需要检测第 67 课意义的「特征序列缺口」，**不应**把「价格上没有成交的 K 线空档」直接当成线段划分缺口的唯一判据。

### 1.4 另一处高发混淆：「缺口＝一段」的两种含义

- 第 64 课说「有些突然性的逆着走势来的缺口，就像 530 那个，就必然要当成一段」——这里的「段」是**走势类型的分解单位**（把缺口看成最低级别的一段走势类型），语境是走势类型的层次，不是特征序列意义上的线段划分。
- 第 67 课的「缺口」是**特征序列元素之间的空档**，用于判定线段是否结束。

原文没有用一个统一术语区分二者，读原文/写程序都必须按上下文分辨。**把第 64 课「缺口＝一段」直接实现成「见到跳空就切一段/就判定线段结束」，是对原文的误读**。

### 1.5 与「画不出下降线段」直接相关的三条硬约束

1. **笔破坏 ≠ 线段破坏**（第 76 课附答疑 2007-09-05，pp1689-1690）：
   网友问「在 7475 上面，08311055 那下来一笔，封闭了缺口，后面也先跌破这一笔的结束点，为什么不是线段呢？」缠答：「**这只是笔破坏，没有线段破坏。**」（L300-303）
   → 即使跳空后的下跌把缺口封闭、并跌破相关笔的结束点，只要没有形成线段破坏，就仍然不能画出下降线段。
2. **缺口被封闭 ≠ 线段被破坏**（第 71 课附答疑 2007-08-21，pp1621，L7168-7172）：
   「线段被笔破坏，那特征序列的缺口被封闭，并不意味着线段一定被破坏，有新的线段产生。」
3. **第二种情况里出现「直接新高/新低」时，三笔仍可能只是一个线段**（第 78 课 pp1710，L677-679）：
   「线段B对线段A是第二种情况，而线段C没有形成第二特征序列的分型又直接新高或新低了，这时候，不能认为这是三个线段，线段A、B、C加起来只能算是一个线段。」

### 1.6 任务六问逐条速答（Q1–Q6，结论均可在下文 R/N 条目与附录中找到原文）

**Q1　笔层面：跳空/缺口是否影响分型的成立、笔的成立、笔的数目？**
- **分型的成立**：不影响构造方式，缺口可以成为顶/底分型的组成部分——"当然可以，关键是符合定义"（R7，2007-08-16，第四册 pp1599）；但缺口**不能替代 K 线根数/时间**——"不行，缺口不说明任何问题，需要的是延续的时间"（R8，2007-09-19，第五册 pp1789）。
- **笔的成立**：不影响——"跳空不改变任何事情，如果这缺口在线段里，还是线段；在笔里，还是笔"（R6，2007-08-30，第四册 pp1667）；笔的几何判据（一顶一底＋顶底之间至少一根不属于两者的 K 线＋顶分型最高 K 线区间至少部分高于底分型最低 K 线区间）不以"是否跳空"为条件（R11，第五册 pp1696）。
- **笔的数目**：原文**没有**"缺口要额外计数/额外成笔"的条文。唯一与数目相关的原话是第 64 课"缺口可以看成是三个缺口的迭加"，但其语境是论证**段**至少三笔的计数（R14），不是增加笔的数目。→ 缺口不改变笔的数目（此为按原文口径的推论，原文无正面条文，见 N2/N7）。

**Q2　线段层面：什么是"特征序列的缺口"？两种情况怎么定义？有缺口时线段终结需要什么额外确认？**
- 定义："特征序列两相邻元素间没有重合区间，称为该序列的一个缺口"（R19，第 67 课，第四册 pp1536）；特征序列元素要作包含关系的非包含处理成"标准特征序列"，且向上线段只考察顶分型、向下线段只考察底分型（R20）。
- 两种情况：第一种＝第一与第二元素间**不存在**特征序列缺口 → 线段在该分型极值处结束（R21）；第二种＝**存在**缺口 → 还必须"从该分型最高点开始的向下一笔开始的序列的特征序列出现底分型"（对向上线段），线段才结束（R22）。
- **额外确认**：必须出现"第二特征序列的分型"；但后一特征序列**不必封闭**前面的缺口，且第二序列的分型**不分第一二种情况，只要有分型就可以**（R23）；第 77 课进一步把第二特征序列简化为"不再分第一、二种情况"（R25）。找不到第二特征序列分型 → 原线段未破坏（R30）。

**Q3　向上跳空后出现下降走势，原文要求怎么划分？何时能确认下降线段？何时上升线段延续？**
- **确认下降线段**（等价于"向上线段在跳空高点结束"）需：① 以跳空高点为假设转折点，取"转折点前线段最后一个特征元素"与"转折点后第一笔"比较区间，若两者不重合即判为第二种情况（R26、R27）；② 下跌序列自身的特征序列（向上笔）出现**底分型**，且第二特征序列不再分第一/二种情况（R22、R25）；③ 若下跌只有一笔，属"未完成的图"，"必须再看两笔"（R40）；④ 若第一笔就破坏前线段并延伸成三笔、且第三笔破第一笔的结束位置，则新线段一定成立（R28）。
- **上升线段延续**：找不到第二特征序列分型——"如果对第二种情况，找不到第二特征序列，那就是原来的线段没被破坏"（R30）；下跌只构成"笔破坏"——"这只是笔破坏，没有线段破坏"（R29）；第二种情况中回落段"没有形成第二特征序列的分型又直接新高或新低了"，则几段合起来只算一个线段（R37）。
- **总纲**：跳空本身不改变任何划分（R6），跳空后的第一笔也不能直接结束前一线段（R15）。

**Q4　原文是否有"突然性逆势跳空本身当成一段／缺口可以看成三个缺口迭加（三笔以上）"的规定？**
- **有，但必须限定语境**。第 64 课原文（第四册 pp1464-1465，L3829-3838，全文见附录 A）："缺口如果包含在一笔中的，像今天早上低开的缺口，没有破坏昨天那笔，是顺着昨天那笔下来的，所以这种缺口和一般的走势没什么区别，缺口还是包含在昨天的一笔里。但有些突然性的逆着走势来的缺口，就像 530 那个，就必然要当成一段，而不能光当成一笔或一笔里的了。……就像 0=0+0+0，缺口可以看成是三个缺口的迭加，这样就有三笔以上了。"
- 该段语境是问答"108-109 为什么不是三段"，讲的是**段的构成/计数**（走势类型分解），紧接着的一句仍是"线段必须要被线段破坏才算是真破坏，单纯的一笔是不能破坏线段的"。→ **不能**由此推出"见到跳空就切线段/就判定线段结束"（见 1.4 与 N7）。

**Q5　原文是否提到"缺口不改变任何东西／在笔里还是笔／在线段里还是线段"？**
- **有，逐字原话**："跳空不改变任何事情，如果这缺口在线段里，还是线段；在笔里，还是笔。"出处：第 75 课附答疑 2007-08-30 16:42，第四册 / PDF PAGE 409 / 印刷页 pp1667 / L8127-8129（提问是"我学你的理论用在期货上咋感到中枢不好找啊,老是跳空"）。

**Q6　原文对"10 秒/分钟级数据跨交易日跳空（夜盘、午休）"有无直接规定？**
- **未规定**（见 N12）。原文涉及的最小粒度讨论只有 1 分钟图（第 56/57 课，R3–R4）与 A 股 9:25 竞价是否需要计入（2007-08-16 16:35："9点25必须算，竞价是最重要的时刻之一"，N10）；对 10 秒数据、夜盘、午休、跨交易日造成的数据缝隙，六册通篇**没有**任何规定。可以援引的只有总纲 R6（"跳空不改变任何事情"），即缺口按普通 K 线/普通走势处理、不为数据缝隙单设规则——但这是**由总纲推出的工程约定**，不是原文直接条文。

## 三、规则清单（R1–R40）

### A 组｜缺口/跳空的一般定性（R1–R10）

**R1｜缺口的定义＝没有成交的区间**
> "何谓缺口，就是在该单位K线图上两相邻的K线间出现没有成交的区间。"
出处：第 77 课《一些概念的再分辨》，第五册 / PDF PAGE 14 / 印刷页 pp1694 / txt L399-400。
要点：缺口是**成交区间**概念，与 K 线图周期无关（级别另见 R9）。

**R2｜缺口回补的定义**
> "而缺口的回补，就是在缺口出现后，该缺口区间最终全部再次出现成交的过程。这个过程，可能在下一K线就出现，也可能永远不再出现。"
出处：第五册 pp1694 / L401-402。
要点：回补＝该区间**全部**再次成交；"部分回补"不是回补。

**R3｜缺口被看成最低级别的（走势成分）**
> "缺口，被看成最低级别的，而1分钟以下级别，在1分钟图上，被看成没有内部结构的线段，所以缺口和1分钟以下级别在1分钟图上是同级别的。"
出处：第 56 课《530 印花税当日行情图解》，第四册 / PDF PAGE 96 / 印刷页 pp1354 / L1819-1821。

**R4｜在任一分析级别的"显微镜"下，缺口就是"没有内部结构的线段"**
> "01 段是跳空缺口，23 段上上下下，很复杂，怎么都是线段？……虽然缺口是最低级别的，当然比 23 段这种要低级别，但在1分钟级别显微镜下，没有区别，都可以看成是没有内部结构的线段。"
出处：第 57 课《当下图解分析再示范》，第四册 / PDF PAGE 106 / 印刷页 pp1364 / L2022-2026。
要点：缺口本身不构成更高级别的结构，不能独立充当该分析级别的线段/笔。

**R5｜跳空不改变走势分解方式**
> "跳空就是最低级别的走势，和不跳空的情况一样。"
出处：第 35 课附答疑，第三册 / PDF PAGE 201 / 印刷页 pp1036 / L3687（缠中说禅 17:04）。

**R6｜跳空不改变笔与线段的划分（总纲）**
> "跳空不改变任何事情，如果这缺口在线段里，还是线段；在笔里，还是笔。"
出处：第 75 课附答疑 2007-08-30 16:42，第四册 / PDF PAGE 409-410 / 印刷页 pp1667-1668 / L8127-8129。
要点：**这是本报告最重要的一条总纲**。任何"因为有跳空所以特殊处理"的实现都缺原文支撑。

**R7｜缺口可以成为顶/底分型的组成部分**
> 问："以前好像讲过缺口视同普通K线，那么如何处理其与其相邻K线的包含关系呢？缺口可以做为顶、底分型的组成部分吗？"
> 答："当然可以，关键是符合定义。"
出处：第 70 课附答疑 2007-08-16 16:17/16:25，第四册 / PDF PAGE 341 / 印刷页 pp1599 / L6704-6706。
要点：缺口不改变分型的构造方式，只要求符合定义；包含关系按普通 K 线处理。

**R8｜缺口不能替代 K 线数量/时间（笔的成立条件不被跳空豁免）**
> 问："'顶分和底分'之间不满足三根K线，K线间有缺口，这个顶分和底分成立不？"
> 答："不行，缺口不说明任何问题，需要的是延续的时间。"
出处：2007-09-19 答疑 16:18，第五册 / PDF PAGE 109 / 印刷页 pp1789 / L2260-2261。
要点：**缺口不豁免笔/分型所需的 K 线数量要求**。

**R9｜缺口的力度分类与级别口径**
> "根据缺口是否回补，就构成了对走势行情力度的一个分类。一、不回补，这显然是强势；二、回补后继续新高或新低，这是平势；三、回补后不能新高、新低，因而出现原来走势的转折，这是弱势。"
> "一般来说，突破性缺口极少回补，而中继性缺口……回补的几率对半……一旦缺口回补后不再新高、新低，那么就意味着原来的趋势发生逆转，这是衰竭性缺口的特征……一个日线级别趋势的衰竭性缺口，至少制造一个周线级别的调整。"
> "注意，这里的级别和缺口所在的K线图无关，只和缠中说禅理论中的走势类型级别有关。"
> "在盘整走势中的缺口，与在趋势中的缺口性质不同，属于普通缺口，这种缺口，一般都回补……唯一的意义，就是在中枢震荡中有一个目标，就是回拉的过程中，几乎肯定能至少拉回补掉缺口的位置。"
出处：第 77 课，第五册 pp1694-1695 / L406-422。
要点：缺口有**力度语义**（强势/平势/弱势）与**级别语义**（只看走势类型级别），但这些都是走势分析用语，**不进入笔/线段的几何定义**。

**R10｜缺口可以是走势/中枢之间的连接成分**
> "在最极端的情况下，在 a+A+b+B+c 的走势系列类型里，a 和 c 并不是必然存在的，而 b 完全可以是一个跳空缺口，这样，整个走势就可以简化为两个孤零零的中枢。"
出处：第 33 课《走势的多义性》，第三册 / PDF PAGE 33 / 印刷页 pp868 / L692-694。
> 问："如果一段向上的走势，某天因除权而产生一个向下的跳空缺口……这个中枢的第一段应该从哪算起，是否应把缺口处当作第一段"
> 答："缺口没什么特别的，你可以把除权缺口当成最低级别的下跌，新的中枢和一般下跌时形成新中枢的处理是一样。然后一切都按中枢的定义来看。"
出处：第 35 课附答疑 2007-03-12 16:09，第三册 / PDF PAGE 77 / 印刷页 pp912 / L1528-1532。
> "两个年中枢之间也可以是一个线段连接，甚至就是缺口连接"（第六册 / PDF PAGE 67 / 印刷页 pp2150 / L1365）。
要点：在**走势类型/中枢**层面，缺口可以充当"最低级别下跌/连接段"；这与线段划分层面要区分开（见 1.4）。

### B 组｜笔与缺口（R11–R16）

**R11｜笔的完整定义（含"顶底区间必须有部分重合"——即笔内部不允许"顶低于底"）**
> "笔，必须是一顶一底，而且顶和底之间至少有一个K线不属于顶分型与底分型。当然，还有一个最显然的，就是在同一笔中，顶分型中最高那K线的区间至少要有一部分高于底分型中最低那K线的区间，如果这条都不满足，也就是顶都在低的范围内或顶比底还低，这显然是不可接受的。"
出处：第 77 课，第五册 / PDF PAGE 16 / 印刷页 pp1696 / L438-441。
要点：第 77 课还给出**笔的唯一性与三步划分法**（确定合格分型 → 同性质分型只保留后面的 → 相邻顶底连成一笔），pp1696-1697 / L462-472。
→ 这是"笔层面"处理缺口的规范依据：缺口只影响 K 线取值，不影响这一几何判据；**只要顶底分型各自成立且满足上述关系，跨缺口的一笔依然成立**。

**R12｜缺口包含在一笔中时，该笔性质不变**
> "因为段必须是至少三笔构成，缺口如果包含在一笔中的，像今天早上低开的缺口，没有破坏昨天那笔，是顺着昨天那笔下来的，所以这种缺口和一般的走势没什么区别，缺口还是包含在昨天的一笔里。"
出处：第 64 课《去机场路上给各位补课》（2007-07-02 21:37:44），第四册 / PDF PAGE 206 / 印刷页 pp1464 / L3829-3831。

**R13｜"逆着走势来的突然性缺口"要当成一段（走势类型意义的段）**
> "但有些突然性的逆着走势来的缺口，就像 530 那个，就必然要当成一段，而不能光当成一笔或一笔里的了。"
出处：同 R12，pp1464-1465 / L3832-3834。
要点：**注意语境**——此处的"段"是走势类型分解中的一段（把缺口当最低级别走势类型），并非特征序列意义上的线段；与 R18 的"缺口是线段三折要求的例外"一起读，不可直接实现为"跳空即切线段"。

**R14｜缺口可视为"0=0+0+0"，从而满足"至少三笔"**
> "有人可能说，缺口没有三笔？那你可以这样去看，就像 0=0+0+0，缺口可以看成是三个缺口的迭加，这样就有三笔以上了。"
出处：同 R12，第四册 pp1465 / L3834-3836。
要点：原文用"迭加"论证缺口可以满足"段至少三笔"的计数要求，属于**计数层面的说理**，不改变特征序列判据。

**R15｜线段必须被线段破坏，单笔不能破坏线段**
> "还有，有位叫袖手旁观的网友理解得也不错，线段必须要被破坏才算结束，但必须要强调的是，线段必须要被线段破坏才算是真破坏，单纯的一笔是不能破坏线段的，这就避免了一些特偶然因数对走势的干扰。"
出处：同 R12，第四册 pp1465 / L3836-3838。
要点：跳空后的第一笔（哪怕很猛烈）**不能**直接结束前一线段。

**R16｜一字涨停/一字跌停的处理：可合并为一根 K 线，但"连分型都算不上"**
> 问："还有例如一只股票开盘就封涨停并且全天没打开过以涨停报收，是否可以把当天所有的K线依次全部合并为一根K线，也就是说当天的走势就可以看成是一个跳空缺口加一根K线？？"
> 答："另外，一字涨停当然可以这样看，所以最开始时就说，这只形成最小级别的中枢。而站在用分型开始构造最小级别中枢的角度，那就连分型都算不上，更不说笔了。"
出处：第 75 课附答疑 2007-08-30 17:00，第四册 / PDF PAGE 410 / 印刷页 pp1668 / L8151-8156。

### C 组｜线段与缺口（R17–R31，核心）

**R17｜线段成立的基本条件：至少三笔、单数、开始三笔必须有重合**
> "线段划分的最基本原则，就是线段必须至少有三笔……线段中包含笔的数目，都是单数的。而且，线段开始的那三笔，必须有重合，开始三笔没有重合的，是构不成线段的。"
出处：第 77 课，第五册 / PDF PAGE 18 / 印刷页 pp1698 / L478-483。
要点：**跳空后的下跌即使幅度巨大，若前几笔之间不重合，也构不成线段**。

**R18｜线段的三折要求及其"缺口例外"**
> "而一个线段，除非是缺口，否则必须由至少上-下-上或下-上-下的三折组成，只要互相相邻的上或下不重合，则这个模式可以一直延伸下去而依然还是一个线段。"
出处：第 58 课（2007-06-04 22:34:47），第四册 / PDF PAGE 126-127 / 印刷页 pp1384-1385 / L2406-2410。
要点：原文明确承认"缺口"是"必须三折"的例外情形之一——这是原文中**唯一**把缺口直接写进线段构成条件的地方；但它只说明缺口可替代三折，未说明缺口本身可判定线段结束。

**R19｜特征序列的定义与"特征序列缺口"的定义**
> "定义：序列 X1X2…Xn 成为以向上笔开始线段的特征序列；序列 S1S2…Sn 成为以向下笔开始线段的特征序列。特征序列两相邻元素间没有重合区间，称为该序列的一个缺口。"
出处：第 67 课《线段的划分标准》（2007-08-01 22:31:55），第四册 / PDF PAGE 278 / 印刷页 pp1536 / L5404-5405。
要点：**这是线段划分中"缺口"的正式定义**——只需区间不重合，与是否存在无成交价格区间无关（见 1.3）。

**R20｜标准特征序列（非包含处理）与"只考察顶分型/底分型"**
> "关于特征序列，把每一元素看成是一K线……也存在所谓的包含关系，也可以对此进行非包含处理。经过非包含处理的特征序列，成为标准特征序列。"
> "注意，以向上笔开始的线段的特征序列，只考察顶分型；以向下笔开始的线段，只考察底分型。"
出处：第 67 课，第四册 pp1536 / L5410-5414。

**R21｜第一种情况（无缺口）：分型极值处即线段终点**
> "第一种情况：特征序列的顶分型中，第一和第二元素间不存在特征序列的缺口，那么该线段在该顶分型的高点处结束，该高点是该线段的终点；……特征序列的底分型中，第一和第二元素间不存在特征序列的缺口，那么该线段在该底分型的低点处结束，该低点是该线段的终点；"
出处：第 67 课，第四册 / PDF PAGE 279 / 印刷页 pp1537 / L5421-5428。

**R22｜第二种情况（有缺口）：必须"第二特征序列出现分型"才算结束**
> "第二种情况：特征序列的顶分型中，第一和第二元素间存在特征序列的缺口，如果从该分型最高点开始的向下一笔开始的序列的特征序列出现底分型，那么该线段在该顶分型的高点处结束，该高点是该线段的终点；……特征序列的底分型中，第一和第二元素间存在特征序列的缺口，如果从该分型最低点开始的向上一笔开始的序列的特征序列出现顶分型，那么该线段在该底分型的低点处结束，该低点是该线段的终点；"
出处：第 67 课，第四册 / PDF PAGE 280 / 印刷页 pp1538 / L5433-5444。
要点：**这就是"有缺口时反向线段如何确认"的原始条文**。对"大幅向上跳空后向下"的场景：向上线段的特征序列出现顶分型且有缺口 → 属第二种情况 → 必须"从该分型最高点开始的向下一笔开始的序列的特征序列出现**底分型**"，向上线段才在最高点结束，才轮到下降线段成立。

**R23｜第二种情况的放松：不必回补缺口，第二序列分型不分第一/第二种情况**
> "强调，在第二种情况下，后一特征序列不一定封闭前一特征序列相应的缺口，而且，第二个序列中的分型，不分第一二种情况，只要有分型就可以。"
出处：第 67 课，第四册 / PDF PAGE 280 / 印刷页 pp1538 / L5448-5449。
要点：**不要把"回补跳空缺口"写成线段结束/反向线段成立的必要条件**。这是最常见的实现级误读。

**R24｜线段结束的前提是"出现特征序列的分型"**
> "上面两种情况，就给出所有线段划分的标准。显然，出现特征序列的分型，是线段结束的前提条件。本课，就是把前面'线段破坏的充要条件就是被另一个线段破坏'精确化了。"
出处：第 67 课，第四册 / PDF PAGE 281 / 印刷页 pp1539 / L5457-5459。

**R25｜第 77 课的简化：第二特征序列不再分第一/二种情况（含收敛性论证）**
> "各位肯定注意，在第二种情况下特别强调，第二特征序列，其实就是对应着线段C对线段B的破坏，不再分第一、二种情况了。这，其实是一个简化的方法。……如果我们坚持线段的最终破坏回补特征序列缺口情况，那么，如果线段C对线段B还是第二种情况，那么线段C的区间肯定就在线段A特征序列缺口与线段B特征序列缺口之间，如此类推，总会出一个线段X，使得对应前面的线段是回补特征序列缺口，否则，这些线段的区间就会无限缩小，最后就会形成一个点，这显然是不可能的……正因为这样，所以在第二种情况中的第二特征序列判断中，就不再分第一、二种情况了"
出处：第 77 课，第五册 / PDF PAGE 18-19 / 印刷页 pp1698-1699 / L495-508。
要点：**这是第 67 课条文在实现上的收敛化处理**——第二特征序列只要出分型即可，否则会推出"区间无限缩小成一个点"的悖论。

**R26｜判据只有一个：第一、第二元素间有无缺口**
> "在67课里，把线段的划分分为两种情况……判断的标准只有一个，就是特征序列的分型中，第一和第二元素间不存在特征序列的缺口。"
出处：第 71 课《线段划分标准的再分辨》（2007-08-16 23:02:06），第四册 / PDF PAGE 348 / 印刷页 pp1606 / L6876-6878。

**R27｜第 71 课的落地程序："假设转折点 → 用两种情况考察"**
> "其实，线段的划分，都是可以当下完成的，无非是如下的程序：假设某转折点是两线段的分界点，然后对此用线段划分的两种情况去考察是否满足，如果满足其中一种，那么这点就是真正的线段的分界点；如果不满足，那就不是，原来的线段依然延续，就这么简单。"
> "特征序列的分型中，第一元素就是以该假设转折点前线段的最后一个特征元素，第二个元素，就是从这转折点开始的第一笔，显然，这两者之间是同方向的，因此，如果这两者之间有缺口，那么就是第二种情况，否则就是第一种，然后根据定义来考察就可以。"
出处：第 71 课，第四册 / PDF PAGE 349 / 印刷页 pp1607 / L6894-6899。
要点：**这是原文给出的唯一可编程判据**，直接对应「程序如何判断转折点是否为线段分界点」。注意第二句给出元素取法：缺口检测发生在「转折点前最后一个特征元素」与「转折点后第一笔」之间。

**R28｜第 71 课的三笔延伸规则（无缺口/近端情形）**
> "从上面的分析就可以知道，从转折点开始，如果第一笔就破坏了前线段，进而该笔延伸出三笔来，其中第三笔破点第一笔的结束位置，那么，新的线段一定形成，前线段一定结束。"
> "这种情况还有更复杂一点的情况，就是第三笔完全在第一笔的范围内，这样，这三笔就分不出是向上还是向下……这种情况，无非两种最后的结果：1、最终还是先破了第一笔的结束位置，这时候，新线段显然成立，旧线段还是被破坏了；2、最终，先破第一笔的开始位置，这样，旧线段只被一笔破坏，接着就延续原来的方向，那么，显然旧线段依然延续，新线段没有出现。"
出处：第 71 课，第四册 / PDF PAGE 348 / 印刷页 pp1606 / L6864-6873。
要点：**"第三笔破第一笔结束位置"是反向线段成立的重要操作判据**；第三笔若完全落在第一笔范围内，则要看后续先破哪个位置（两分支）。

**R29｜笔破坏 ≠ 线段破坏（两个独立概念）**
> 问："在7475上面，08311055那下来一笔，封闭了缺口，后面也先跌破这一笔的结束点，为什么不是线段呢？"
> 答："这只是笔破坏，没有线段破坏。"
出处：第 76 课附答疑 2007-09-05 16:35/16:52，第五册 / PDF PAGE 10 / 印刷页 pp1690 / L300-303。
> 另：「81、82这个分段为什么中间那个高点不是一个段呢？」答：「因为那只是一笔，笔破坏不等于线段破坏。」（第五册 pp1689 / L274-275）

### D 组｜线段破坏的后续判断、包含关系与更正（R32–R40）

**R32｜缺口封闭 ≠ 线段破坏**
